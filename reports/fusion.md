# Audio + RF fusion: ablation

**Read as an upper bound.** No corpus has audio and RF of the same flight, so each pair is an audio window and an RF window of the same class drawn independently, which is exactly the independence the sum rule assumes. RF is the v2 detector (`rf_v2.md`), retrained after v1 called pure noise "drone" (`rf_tampere.md`); its real negatives still come from one lab, so RF false alarms on real-world Wi-Fi / Bluetooth are unmeasured. Each sensor's evidence is capped at +-5 (log-likelihood ratio); the cap does not stop one confident sensor from deciding alone, because the fused threshold sits below zero. Generated by `scripts/eval_fusion.py`.

Audio: tier-4 detector on the outdoor Svanström test set (drone, helicopter, outdoor background). RF: DroneRF held-out time and held-out Tampere drones (positives), DroneRF background (negatives). Each sensor's score is calibrated to a log-likelihood ratio on its own validation windows (balanced Platt scaling). `sum` adds the two; `learned` is the proposal's fusion layer, a logistic regression on the two, fitted on validation pairs (weights audio 1.01, RF 1.60). `OR` / `AND` combine each sensor's own frozen decision. Fused thresholds: 1% FPR on validation pairs. 4000 pairs per class per scenario; CIs resample audio recordings.

## Helicopter false alarms (both sensors present)

Audio confuses helicopters with drones; RF sees no drone link.

| method | helicopter false-alarm rate |
|---|---|
| audio only | 0.014 |
| RF only | 0.000 |
| OR | 0.014 |
| AND | 0.000 |
| sum | 0.011 |
| learned | 0.000 |

## What this shows

- With both sensors, fusion is as good as RF alone (recall 0.995 sum, 0.993 RF only). RF v2 is near-perfect on these test windows, so there is little left for audio to add here; its real negatives come from one lab, so this is RF's best case.
- RF-silent drone: the sum keeps audio's recall (0.184 vs 0.223 audio only); the learned layer drops to 0.002, because it weights RF 1.60 vs audio 1.01 and never saw a drone without a radio link.
- OR catches the most but has the most false alarms (0.0067); AND has the fewest (0.0000) but misses whatever one sensor misses.
- Helicopter false alarms: audio only 0.014, sum 0.011, AND 0.000.
- Receiver noise with no drone: false alarms RF only 0.013, OR 0.023, sum 0.028, AND 0.000; the sum is above the 1% target here (with the v1 RF detector every rule but AND reached 1.000). The cap would not have saved a fooled RF sensor: the fused threshold sits below zero, so capped RF evidence crosses it whenever audio is neutral.
- RF on a new receiver (Tampere drones): RF-only recall 1.000, sum 1.000.
