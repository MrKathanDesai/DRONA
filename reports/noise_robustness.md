# Noise robustness (tier 1)

Held-out indoor test recordings (tier 1), each clip mixed with noise at SNR 20 dB (low), 10 dB (medium) and 0 dB (high). The threshold is fixed at 1% FPR on **clean** validation negatives and never re-tuned, so FPR above 1% means the noise itself triggers alarms. Generated by `scripts/eval_noise.py`.

- Noise sources: ESC-50 recordings from the tier-1 test split only (augmentation used train-split recordings only).
- **voice** = laughing, coughing, crying baby, sneezing (ESC-50 has no speech).
- **music** is synthetic (random chords + kick drum; ESC-50 has no music).
- **mixed** = voice + traffic + wind + environment + music at equal power.
- **speech** = real read speech (LibriSpeech dev-clean), **music_real** = real music (GTZAN, 10 genres). Test noise and augmentation noise come from different speakers / excerpts. Augmentation never used these two, so they also test whether it carries over to unseen noise types.
- `pretrained + aug` was trained on clean clips plus one noisy copy of each (condition and SNR 0-20 dB drawn at random). Its settings were fixed before any test result was seen.

## What this shows

- **Mild noise (20 dB) barely matters.** Pretrained recall moves by at most 0.016 from clean (0.878).
- **Loud noise (0 dB) cuts recall sharply** for the clean-trained head, to 0.27-0.74 across conditions.
- **Noise augmentation at 0 dB** changes recall by +0.04 to +0.31 across conditions (speech +0.31, real music +0.11, neither seen in training), with clean recall unchanged (0.878 -> 0.882). Its clean false-alarm rate is 0.9% vs 0.6%, still within the 1% target.
- **The noise itself causes false alarms** mainly for music at 0 dB (8.7% clean-trained, 4.2% augmented; target 1%).
- **The classical baseline is more robust in some conditions** at 0 dB (voice, environment, speech), and keeps the lowest false-alarm rate throughout, at the cost of lower clean recall.
- Test noise pools: voice 111 clips, traffic 132 clips, wind 25 clips, environment 186 clips, speech 400 clips, music_real 1996 clips. The wind pool is small, so wind results rest on few recordings.

## Caveats

- Mixing is additive at a fixed SNR. Real masking also involves reverberation, distance and microphone response, which are not simulated.
- Indoor tier-1 test only; outdoor performance is already the weak point (see `outdoor_audio.md`) and is not re-tested here.
