# Outdoor aircraft: false alarms on real overflights

AeroSonicDB (YPAD-0523, CC BY-NC 4.0): ADS-B-labelled recordings of low-flying aircraft near Adelaide airport, annotated with when each aircraft is audible, plus outdoor clips of the same places with no aircraft. Its own split keeps each recording session on one side. Test sessions: 99 aircraft and 317 no-aircraft recordings. 1 s windows from the audible interval (at most 20 per recording). Generated by `scripts/eval_aircraft.py`.

- **original**: the deployed tier-4 detector, never trained on aircraft overflights.
- **retrained**: the same recipe with AeroSonicDB *training* sessions as negatives (20009 windows; fold 5 used for the threshold).
