# RF drone detection (DroneRF)

**Do not read these scores as detection performance.** On windows at the noise floor, with nothing visibly transmitting, the forest still separates drone from background at AUC 1.000 (344 train, 56 test windows). That points to the recording session or receiver, and background is one session, so DroneRF alone cannot remove it. A weak drone signal below the level cut is not ruled out.

Log-PSD per 25 ms window, both halves of the 2.4 GHz band. Threshold fixed on held-out negatives at 1% FPR, applied unchanged to test. CIs resample blocks of 3 consecutive segments. Generated by `scripts/train_rf.py`.

- tier 1: last blocks of each recording held out, same drones
- tier 2: one drone never trained on, plus the last background blocks
- no tier 3: DroneRF is a single lab session, so nothing here measures another place, range or receiver

`forest+level` keeps absolute level and is a shortcut probe, not a candidate. Every other row is level-invariant.

Level alone, AUC: low band 0.908, high band 0.504.
